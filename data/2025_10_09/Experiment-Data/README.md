## Files

- `ro-crate-metadata.json`: contains machine readable metadata about this submission
- `manifest-sha256.txt`: contains the sha256 checksum of all files (excluding itself)
- `data/`: contains used background frames, MMDetection3D configuration and model checkpoint weights for training with the datasets.
- `experiments/`: contains the compressed ros2 bags of the conducted experiments
